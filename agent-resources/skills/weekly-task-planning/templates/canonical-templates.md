# Template canonical cho task tuần

Skill này không sở hữu template. Dùng trực tiếp các nguồn sau:

| Mục đích | Nguồn canonical |
| --- | --- |
| Tổng quan tuần | `docs/processed/plan/weekly/templates/weekly-overview.md` |
| Card task tuần | `docs/processed/plan/weekly/templates/weekly-task.md` |
| Input task cá nhân | `workspace/_templates/task/input/task-input.md` |
| Output task cá nhân | `workspace/_templates/task/output/task-output.md` |
| Commit message | `.github/commit-message-template.md` |
| Pull request | `.github/pull_request_template.md` |

Không tạo hoặc duy trì bản sao template trong thư mục skill.
