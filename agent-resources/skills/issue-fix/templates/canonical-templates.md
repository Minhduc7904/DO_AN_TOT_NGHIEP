# Nguồn canonical cho xử lý issue

Skill này không sở hữu template. Khi xử lý issue, dùng trực tiếp các nguồn sau:

| Mục đích | Nguồn canonical |
| --- | --- |
| Ticket issue | `docs/processed/issues/templates/issue-ticket.md` |
| Trạng thái và quy tắc ticket | `docs/processed/issues/README.md` |
| Pull request | `.github/pull_request_template.md` |
| Commit message | `.github/commit-message-template.md` |
| Quy tắc branch, PR, review, merge | `docs/processed/rules/git-and-pull-request-rules.md` |
| Quy tắc đặt tên branch và file | `docs/processed/rules/naming-rules.md` |

Không tạo hoặc duy trì bản sao template trong thư mục skill.
