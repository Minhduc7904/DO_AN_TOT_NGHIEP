# Template canonical cho review

Skill này không sở hữu template. Dùng trực tiếp các nguồn sau khi đối chiếu PR và hồ sơ:

| Mục đích | Nguồn canonical |
| --- | --- |
| Pull request | `.github/pull_request_template.md` |
| Output task | `workspace/_templates/task/output/task-output.md` |
| Input task | `workspace/_templates/task/input/task-input.md` |
| Card task tuần | `docs/processed/plan/weekly/templates/weekly-task.md` |

Không tạo hoặc duy trì bản sao template trong thư mục skill.
