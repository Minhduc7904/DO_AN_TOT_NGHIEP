# Template canonical

Skill này không sở hữu template. Các đường dẫn sau là nguồn sự thật duy nhất và phải được dùng trực tiếp khi cần khởi tạo tài liệu:

| Mục đích | Nguồn canonical |
| --- | --- |
| Input task | `workspace/_templates/task/input/task-input.md` |
| Output task | `workspace/_templates/task/output/task-output.md` |
| Tổng quan tuần | `docs/processed/plan/weekly/templates/weekly-overview.md` |
| Card task tuần | `docs/processed/plan/weekly/templates/weekly-task.md` |
| Commit message | `.github/commit-message-template.md` |
| Pull request | `.github/pull_request_template.md` |
| Biên bản họp | `meetings/_templates/meeting-notes.md` |

Không tạo, sao chép để duy trì, hoặc chỉnh sửa một bản template khác trong thư mục skill.
